❓ Guide d’utilisation

Tout ce qu’il faut savoir pour profiter de l’application en famille.

🔑 Se connecter

Écrivez votre nom complet (ou votre fonction : Président, Trésorier, Secrétaire) et choisissez un code secret d’au moins 4 caractères à la première connexion. Vous pouvez le changer dans « Mon Profil ». Code oublié : demandez au bureau de réinitialiser les codes.

🎂 Annuaire et anniversaires

Les anniversaires s’écrivent JJ/MM (ex : 15/11). Touchez un membre pour voir son profil, l’appeler ou lui écrire. Les numéros ne sont visibles que pour les personnes connectées. Le bureau ajoute et modifie les membres ; chacun peut modifier son propre profil.

💌 Messages et vocaux

Enregistrez un vocal de 3 minutes au maximum ou écrivez un message, puis partagez-le avec la famille. Chacun peut répondre et supprimer ses propres messages.

💰 Cotisations

Le statut « À jour » repart à zéro chaque mois. Le Trésorier enregistre les cotisations et les dépenses de la caisse. Pour un événement, le bureau peut ouvrir une cotisation avec un collecteur, qui peut afficher ou masquer la liste des Aînés et celle des Jeunes.

📹 Réunion vidéo

Depuis « Réunion vidéo » ou un événement, touchez « Rejoindre ». Seuls les membres connectés entrent. La première personne qui lance la réunion doit se connecter avec un compte Google ou GitHub : elle devient l’animateur.

📲 Installer l’application

Sur Android : touchez « Installer l’application ». Sur iPhone : bouton Partager puis « Sur l’écran d’accueil ». Elle s’ouvre ensuite comme une vraie application, même avec une mauvaise connexion.

🛡️ Erreur de caisse

Le Trésorier indique le motif puis touche ↩ à côté de l’opération concernée. L’annulation n’est appliquée qu’après l’accord de 3 membres du bureau (la demande compte comme la première approbation). Chacun vote dans « Validations du bureau ». Le journal garde la trace de tout.

🗳️ Sondages

Le bureau publie une question avec 2 à 6 choix. Chaque membre connecté vote une fois et peut changer d’avis tant que le sondage est ouvert. Les résultats s’affichent en pourcentages, sans les noms.

🔒 Vos données

Les informations restent sur votre appareil, ou sont partagées entre les membres grâce au code famille. Ne communiquez ce code qu’à la famille. Le bureau peut télécharger une sauvegarde depuis l’espace administrateur.

🛡️ Validations du bureau

Une opération de caisse ne peut être annulée qu’avec l’accord de 3 membres du bureau. La demande du Trésorier compte comme la première approbation.

🗳️ Sondages de la famille

Donnez votre avis sur une date, un lieu, un projet… Vous pouvez changer votre vote tant que le sondage est ouvert.
